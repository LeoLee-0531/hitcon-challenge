# 網站規格
## 產品定位與目標

- **定位**：一個具故事性的線上闖關活動主站，串連多個外部關卡，支援中英雙語，提供進度地圖、QRcode 領獎、管理後台等功能。
- **目標**：讓參加者能流暢體驗闖關流程，主辦方能方便管理與即時掌握活動狀況。

---

## 架構總覽

## 前端（Next.js + TypeScript）

- 首頁（故事簡介、活動說明、登入/註冊、公告）
- 闖關地圖（顯示所有關卡進度，曲線連線設計）
- 闖關詳情（每關標題、說明、外部連結、密碼輸入）
- 個人頁面（顯示通關進度、QRcode 領獎頁）
- 多語言切換（中/英，localStorage 記憶偏好）
- 管理後台（/admin，管理員密碼登入）

## 後端（Express + TypeScript）

- 使用者管理（Google OAuth 登入、資料儲存）
- 闖關進度管理（每關卡通關狀態、密碼驗證）
- QRcode 領獎管理（產生、驗證、失效、紀錄）
- 公告管理（新增、編輯）
- 管理員登入（密碼登入，無重設機制）
- API 文件（Swagger，自動產生）

## 資料庫 ( MongoDB + Prisma )

- 使用者資料（Google 資訊、語言偏好、闖關進度）
- 闖關資料（標題、說明、連結、中英內容、密碼）
- QRcode 領獎紀錄
- 公告資料

---

## 主要功能與流程

## 使用者端

- **Google OAuth 登入/註冊**，自動取得暱稱、email
- **多語言切換**（中/英，localStorage 記憶）
- **首頁**：活動故事、說明、公告（可手動隱藏）
- **闖關地圖**：曲線連線，顯示所有關卡進度，點擊節點展開關卡說明與外部連結
- **闖關詳情**：顯示關卡標題、說明、外部連結、密碼輸入欄
- **密碼驗證**：輸入正確密碼後標記通關，錯誤有彈窗提示
- **個人頁面**：顯示通關進度、已完成關卡、QRcode 領獎按鈕
- **QRcode 領獎**：通關後自動產生，掃描後即失效，前後端皆有提醒
- **RWD 支援**：手機、平板、桌機皆可流暢操作
- **動畫效果**：地圖節點亮起、線條流動、彈窗提示、loading 動畫

## 管理員端

- **/admin 密碼登入**（無重設機制）
- **公告管理**：新增、編輯 (支援中英內容）
- **闖關紀錄查詢**：查詢所有使用者闖關進度
- **活動數據統計**：顯示通關人數、各關卡通過率等
- **QRcode 領獎管理**：掃描 QRcode 標記領獎、手動補發 QRcode
- **API 文件（Swagger）**：自動產生，前後端皆可參考


## QRcode 生成與分級獎勵邏輯

- **分級獎勵規則**
   - 闖關者通過 3、5、7 關時，分別可獲得一級、二級、三級獎勵 (暫定)
   - 每個等級只能領一次獎勵，且不可重複領取
- **QRcode 產生**
   - QRcode 為該闖關者的 userId
- **管理員掃描流程**
   - 管理員掃描 QRcode（userId），系統查詢該使用者目前通關數與已領獎等級
   - 系統顯示：
       - 該使用者目前通關數（如 5 關）
       - 可領取的獎勵等級（如一級、二級）
       - 已領取的獎勵等級（如一級已領取，二級未領取）
   - 若通等級不足第一級，顯示「資格未達標，無法領獎」
   - 若有可領取等級，管理員可按下「領獎」按鈕，系統自動標記所有可領取等級為「已領取」
   - 領獎後，系統即時更新狀態，避免重複領取

## UI/UX 規劃

- **主色系**：深灰/黑底 + 螢光綠點綴（參考 Hack The Box）
- **Logo**：使用你提供的圖檔
- **地圖設計**：曲線連線，節點互動動畫，進度一目了然
- **彈窗/提示**：密碼錯誤、通關成功、QRcode 產生、公告推播等皆用彈窗提示
- **多語言**：所有內容（關卡、公告、說明）皆有中英版本，切換即時生效
- **RWD**：手機版地圖可滑動，按鈕大，操作直覺
- **動畫**：以順暢為主，地圖節點亮起、線條流動、loading 動畫

## 技術選型

- **前端**：Next.js + TypeScript
- **後端**：Express + TypeScript
- **資料庫**：MongoDB + Prisma
- **OAuth**：Google
- **部署**：Vercel（前端）、Render（後端）、UptimeRobot（監控）
- **API 文件**：Swagger，自動產生

---

## 部署與維運

- **主站與外部關卡分開部署**，各自獨立網址
- **監控**：UptimeRobot 監控主站與各關卡，異常自動通知
- **SSL/HTTPS**：全站啟用
- **資料備份**：活動期間定期備份資料庫

---

## 其他注意事項

- **內容管理**：所有中英文內容由主辦方提供，開發時直接寫入資料庫或設定檔
- **安全性**：管理員登入頁加強保護（如路徑不公開、密碼複雜）
- **公告推播**：使用者可手動隱藏公告
- **無需排行、成就、email 通知、密碼驗證碼、音效**

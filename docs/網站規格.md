# 主站規格

## UI/UX

- **主色系**：深灰/黑底 + 螢光綠點綴（參考 Hack The Box）
- **Logo**：SITCON Logo
- **彈窗/提示**：密碼錯誤、通關成功、QRcode 產生、公告推播等皆用彈窗提示
- **雙語言**：所有內容（關卡、公告、說明）皆有中英版本，切換即時生效
- **RWD**：手機版地圖可滑動，按鈕大，操作直覺
- **動畫**：以順暢為主，地圖節點亮起、線條流動、loading 動畫

## 功能

### 使用者端

- **Google OAuth 登入/註冊**：自動取得暱稱、email
- **雙語言切換**：中/英，localStorage 記憶 ( 使用 next i18n )
- **首頁**：活動故事、說明、公告（可手動隱藏）
- **闖關進度**：顯示所有關卡進度，點擊節點展開關卡說明與外部連結
    - **各闖關詳情**：顯示關卡標題、說明、外部連結、密碼輸入欄
    - **關卡密碼驗證**：輸入正確密碼後標記通關，錯誤有彈窗提示
- **個人頁面**：顯示通關進度、已完成關卡、領獎等級、領獎按鈕

### 管理員端（暫時不做）

- **/admin 密碼登入**（預設：SITCON2025）
- **公告管理**：新增、編輯（支援中英內容）
- **闖關紀錄查詢 & 領獎管理**：查詢特定使用者闖關進度、獎品等級、重製領獎
- **活動數據統計**：顯示通關人數、各關卡通過率等

### 分級獎勵

- **分級獎勵規則**
   - 分為三個等級，闖關者通過 3、5、7 關時，分別可獲得一級、二級、三級獎勵
   - 只能領取一次獎勵，不分任何等級
- **領獎流程**：
   - 闖關者點擊領獎按鈕後，系統生成一個領獎 QRcode，對應獎勵等級
- **管理員掃描流程**
   - 管理員掃描闖關者的領獎 QRcode，系統查詢該使用者目前通關數與已領獎等級
   - 系統顯示：
       - 使用者 id
       - 獎勵等級
   - 領獎後，系統即時更新狀態，避免重複領取

## 技術

- **前端**：Next.js + TypeScript
- **多語言**：next i18n
- **後端**：Express + TypeScript
- **資料庫**：MongoDB + Prisma
- **OAuth**：Google
- **部署**：Vercel（前端）、Render（後端）、UptimeRobot（監控）
- **API 文件**：Swagger
:::info
各外部關卡獨立部署
:::


## 其他注意事項

- **內容管理**：需要提供所有中/英文內容，開發時直接寫入資料庫或設定檔
- **公告推播**：使用者可手動隱藏公告
- **未來可增加功能**：email 通知 ( 闖關完成 QRcode )

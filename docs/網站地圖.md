# 網站地圖

## 公開區（未登入可見）
- `/` 首頁
  - 活動簡介（中/英）
  - 登入按鈕（Google OAuth）
  - 活動規則、流程說明
  - FAQ、聯絡我們
- `/login` 登入頁（可直接用 Google OAuth）

## 闖關區 ( 需登入 )
- `/story` 開頭故事
- `/challenge-map` 闖關進度地圖
    - 可視化顯示已完成關卡、未完成關卡
    - 進入各關卡按鈕
- `/challenge/[id]` 闖關頁（每個關卡一頁，支援外部關卡串接）
  - 關卡說明
  - 進入外部關卡（新分頁或 iframe）
  - 密碼驗證
- `/profile` 使用者主控台
  - 個人資訊 (暱稱、信箱、進度) 
  - 顯示可兌換獎勵（依完成進度分級）
  - 產生/顯示 QRcode（分級）

## 管理後台（需管理員權限）
- `/admin` 後台登入
- `/admin/dashboard`
  - 活動總覽（參加人數、關卡完成率等統計）
- `/admin/announcement` 公告管理
  - 新增/修改公告
- `/admin/rewards` 獎勵管理 
  - 掃描 QRcode 領講

### 非必要功能
- `/admin/users` 使用者管理  
  - 查詢、編輯、停權
- `/admin/challenges` 關卡管理  
  - 新增/編輯/刪除關卡
  - 設定外部串接資訊
- `/admin/logs` 操作紀錄／審核
